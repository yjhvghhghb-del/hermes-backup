## What would fix this

2. Store it as `GITHUB_TOKEN=ghp_...` in `~/.hermes/.env`
3. Add to git remote: `git remote set-url origin https://ghp_TOKEN@github.com/ClawTwice/hermes-backup.git`
4. Create the repo: `curl -s -X POST -H "Authorization: token $GITHUB_TOKEN" -d '{"name":"hermes-backup","private":true}' https://api.github.com/user/repos`
