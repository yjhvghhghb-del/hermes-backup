## Telegram Notification — What Works

**`curl` with `socks5h://` FAILS** (returns 401 Unauthorized):
```bash
curl -s -x socks5h://10.1.252.196:7891 \
  "https://api.telegram.org/bot8800919754:.../sendMessage" \
  -d "chat_id=877708648&text=..."
# → {"ok":false,"error_code":401,"description":"Unauthorized"}
```

**Python `requests` with `socks5h://` WORKS**:
```python
import requests, os

with open(os.path.expanduser('~/.hermes/.env')) as f:
    for line in f:
        if 'TELEGRAM_BOT_TOKEN' in line:
            TOKEN = line.split('=')[1].strip()
            break

proxies = {'https': 'socks5h://10.1.252.196:7891'}
msg = '📦 Hermes 每日备份完成 (2026-09-12 03:01)\n• 已 push origin main ✅'
r = requests.post(f'https://api.telegram.org/bot{TOKEN}/sendMessage',
    json={'chat_id': '877708648', 'text': msg}, proxies=proxies, timeout=15)
print(r.status_code, r.text[:200])
# → 200 {"ok":true,"result":{...}}
```

**Key**: Read token from `~/.hermes/.env` dynamically — do NOT hardcode. The token format in `.env` is `TELEGRAM_BOT_TOKEN=8800919754:AAEQ...`.
