# Session 2026-09-05 — Repo Existed But Had Wrong Remote + Working Dir Mismatch

## What Happened

1. Local commit `9f71598` succeeded — backup was captured correctly
2. `git push origin main` failed because repo didn't exist at `ClawTwice/hermes-backup`
3. SSH push (`git@github.com:`) times out on Termux even with SSH key — connection hangs at banner
4. HTTPS push requires embedded PAT, which is missing

## Root Causes

| Issue | Detail |
|-------|--------|
| Repo doesn't exist | `ClawTwice/hermes-backup` → 404. Repo needs to be created via API with a valid PAT |
| SSH fails | `ssh -i ~/.ssh/hermes_ed25519` → "Connection timed out during banner exchange". Termux cannot complete TCP handshake to github.com:22 even with proxy |
| HTTPS requires PAT | No `$GITHUB_TOKEN`, no `gh auth`, no `.netrc`. Remote URL shows `git@github.com:ClawTwice/hermes-backup.git` (SSH format, not HTTPS) |
| Working dir confusion | `~/hermes-backup-git` is the actual git repo (not `~/hermes-backup`). Both exist. `backup.tar.gz` symlink points to `hermes-backup-daily.tar.gz` in the same dir |

## Working Pattern Discovered

```bash
# Proxy works for HTTPS API calls (curl)
curl -s --proxy http://172.19.0.1:7890 \
  https://api.github.com/repos/ClawTwice/hermes-backup
# → 200 with data

# Git push over HTTPS with embedded token (only working approach)
cd ~/hermes-backup-git
git remote set-url origin "https://$GITHUB_TOKEN@github.com/ClawTwice/hermes-backup.git"
git push origin main
```

## Required Fix (One-Time, Needs老公)

1. Generate GitHub PAT at https://github.com/settings/tokens (scope: `repo`)
2. Store in Termux: `echo 'export GITHUB_TOKEN="ghp_..."' >> ~/.bashrc && source ~/.bashrc`
3. Create repo: `curl -s -X POST -H "Authorization: token $GITHUB_TOKEN" -H "Content-Type: application/json" -d '{"name":"hermes-backup","private":true}' https://api.github.com/user/repos`
4. Switch remote to HTTPS with token embedded, then push

## What Was Working

- `hermes-backup-daily.tar.gz` (21MB) created fresh each run from live `~/.hermes/` dirs
- Local git commit succeeds and preserves history
- Telegram notification pattern works
- Proxy (`172.19.0.1:7890`) handles HTTPS API calls fine
