# Session 2026-09-06 — hermes-backup cron run

## What happened

Backup ran successfully (tar + git commit ✓) but push failed.

### Root cause: SSH remote times out, HTTPS needs embedded PAT

- Remote URL: `git@github.com:ClawTwice/hermes-backup.git` (SSH)
- `ssh -o ConnectTimeout=5 -T git@github.com` → **timed out** (port 22 blocked on Termux)
- `curl https://github.com` → 200 (HTTPS port 443 works fine)
- Tried switching to HTTPS remote → `fatal: could not read Username for 'https://github.com': terminal prompts disabled` (no credentials anywhere)

### Diagnosis commands used

```bash
# GitHub reachable via HTTPS?
curl -s --connect-timeout 10 -o /dev/null -w "%{http_code}" https://github.com
# → 200 ✓

# SSH push fails immediately (port 22 blocked)
ssh -o ConnectTimeout=5 -T git@github.com 2>&1 | head -3
# → timed out

# Current remote URL
git -C ~/hermes-backup-git remote get-url origin
# → git@github.com:ClawTwice/hermes-backup.git (SSH)

# Switch to HTTPS with embedded PAT
git remote set-url origin https://github.com/ClawTwice/hermes-backup.git
GIT_TERMINAL_PROMPT=0 git push origin main
# → fatal: could not read Username (no credentials)

# Check gh auth
gh auth status 2>&1 | head -3
# → not logged in

# Check GITHUB_TOKEN env var
echo $GITHUB_TOKEN
# → empty
```

## Verdict

- Local commit: `c3dcb38 2026-09-06 daily backup` ✓
- Push: ❌ pending — needs `$GITHUB_TOKEN` env var or PAT embedded in HTTPS remote URL
- Next run will fail the same way until credentials are configured

## Fix needed

```bash
# Option A: set GITHUB_TOKEN in environment (persistent: add to ~/.bashrc)
export GITHUB_TOKEN="ghp_YOUR_TOKEN_HERE"

# Option B: embed PAT in HTTPS remote URL
cd ~/hermes-backup-git
git remote set-url origin "https://$GITHUB_TOKEN@github.com/ClawTwice/hermes-backup.git"
git push origin main
```

## Key lesson

SSH (`git@github.com:`) does NOT work on Termux — port 22 is blocked. Must use HTTPS with embedded PAT. Without `$GITHUB_TOKEN` set and without PAT in the URL, HTTPS push also fails. Both conditions must be met.
