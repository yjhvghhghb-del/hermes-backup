# 知识库问答技能

## 知识库位置
`~/.hermes/knowledge/我是老公/数码知识库.md`

## 流程
1. 用 `search_files` 在知识库中搜索关键词
2. 找到相关Q&A后，将答案注入上下文
3. 如果知识库没有，再使用 `web_search` 上网搜索

## 搜索示例
- 蓝屏 → 搜索 "蓝屏"
- 电脑卡 → 搜索 "卡顿"
- 路由器设置 → 搜索 "路由器"
- 手机死机 → 搜索 "手机死机"
